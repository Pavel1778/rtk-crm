# Каталог кодов ошибок API

Требование НФТ-3 ТЗ: у ошибок должны быть стабильные коды, чтобы фронтенд
показывал понятное сообщение по коду, а не только по HTTP-статусу.

Формат ответа при ошибке:

```json
{
  "detail": "Человекочитаемое сообщение",
  "code": "MACHINE_READABLE_CODE"
}
```

| Код | HTTP | Когда возникает | Пример сообщения |
|---|---|---|---|
| `AUTH_INVALID_CREDENTIALS` | 401 | Неверный email или пароль | «Неверный email или пароль» |
| `AUTH_TOKEN_EXPIRED` | 401 | JWT истёк или некорректен | «Сессия истекла, войдите снова» |
| `FORBIDDEN_ROLE` | 403 | Роли не хватает прав | «Недостаточно прав» |
| `ACCOUNT_DISABLED` | 403 | Учётная запись отключена | «Учётная запись отключена» |
| `RESOURCE_NOT_FOUND` | 404 | Сущность не найдена | «Вуз не найден» |
| `STATUS_HAS_ACTIVE_REQUESTS` | 409 | Удаление этапа с заявками | «На этапе N взаимодействий. Укажите перенос» |
| `DUPLICATE_INTERACTION` | 409 | Дублирующая пара вуза и продукта | «Такое взаимодействие уже зарегистрировано» |
| `DUPLICATE_VUZ_NAME` | 409 | Дубль вуза при импорте | «Вуз уже существует» |
| `MAX_PARALLEL_INTERACTIONS` | 409 | Больше 2 активных взаимодействий у вуза | «У вуза уже 2 активных взаимодействия» |
| `WORKFLOW_SCOPE_MISMATCH` | 409 | Этап из другого workflow | «Этап принадлежит другому workflow» |
| `VALIDATION_FAILED` | 422 | Ошибка Pydantic-схемы | «Поле X обязательно» |
| `IMPORT_FILE_CORRUPTED` | 422 | Битая кодировка или структура файла | «Файл повреждён, проверьте кодировку» |
| `RATE_LIMITED` | 429 | Превышен лимит попыток входа | «Слишком много попыток, попробуйте через минуту» |
| `INTERNAL_ERROR` | 500 | Непредвиденная ошибка | «Внутренняя ошибка, попробуйте позже» |

## Реализация

- `MAX_PARALLEL_INTERACTIONS` и `WORKFLOW_SCOPE_MISMATCH` возвращаются в
  `backend/api/interactions.py`.
- `RATE_LIMITED` — в `backend/middleware/rate_limit.py`.
- `VALIDATION_FAILED` — глобальный обработчик `RequestValidationError` в
  `backend/main.py`.
