# Презентация RTK CRM (ЛЦТ 2026)

`RTK-CRM-LCT2026.pptx` — 14 слайдов, формат 16:9, шрифт Montserrat,
палитра шаблона ЛЦТ (`#FF0053`, `#520977`, `#310F53`).

Слайды собраны **строго на официальном шаблоне** `template-lct2026.pptx`
(файл организаторов). Из шаблона взяты обязательные блоки и макеты разделов;
текст-заполнитель заменён содержимым проекта, оформление не менялось.

Состав, роли, город и контакты задаются в `TEAM`, `CITY`, `CONTACT` в
`build_presentation.py`. QR-коды участников ведут на их профили в Telegram,
QR на последнем слайде — на репозиторий; они рисуются автоматически.

## Пересборка

```bash
python3 docs/presentation/build_presentation.py
```

Скрипт требует `python-pptx` и `qrcode`. Скриншоты интерфейса берутся из
`docs/images/`; отсутствующая картинка заменяется заглушкой, сборка не падает.

## Проверка вёрстки

```bash
soffice --headless --convert-to pdf --outdir /tmp/render \
  docs/presentation/RTK-CRM-LCT2026.pptx
```

Конвертация в PDF подтверждает, что текст не выходит за границы слайдов и
шрифт Montserrat встроен. Полная версия питча для речи — `docs/pitch.md`.
