# Презентация RTK CRM (ЛЦТ 2026)

`RTK-CRM-LCT2026.pptx` — 10 слайдов, формат 16:9, шрифт Montserrat,
палитра шаблона ЛЦТ (`#FF0053`, `#310F53`).

## Что заполнить перед защитой

Данные команды в репозитории не зафиксированы, поэтому в презентации стоят
плейсхолдеры. Перед защитой замените их в `build_presentation.py`:

| Поле | Текущее значение | Где |
| --- | --- | --- |
| Состав команды | `ФИО капитана`, `ФИО участника` | `TEAM` |
| Роли | текст ролей в `role` | `TEAM` |
| Ники в мессенджере | `ник в Telegram` | `TEAM` |
| QR-коды участников | рамки `QR` | `tg_url` в `TEAM` |
| Город | `город и регион` | `CITY` |
| Контакт команды | `team@rtk-crm.ru` | `TEAM_CONTACT` |
| Логотипы постановщика | место на титульном слайде | слайд 1 |

QR-код рисуется автоматически, как только у участника заполнен `tg_url`
(ссылка вида `https://t.me/username`). Пока поле пустое, на слайде остаётся
рамка-заглушка.

## Пересборка

```bash
python3 docs/presentation/build_presentation.py
```

Скрипт требует `python-pptx` и `qrcode`. Скриншоты интерфейса берутся из
`docs/images/`; отсутствующая картинка заменяется заглушкой, сборка не падает.

## Проверка вёрстки

```bash
soffice --headless --convert-to pdf --outdir /tmp/render \
  docs/presentation/RTK-CRM-LCT2026.pptx
```

Конвертация в PDF подтверждает, что текст не выходит за границы слайдов и
шрифт Montserrat встроен. Полная версия питча для речи — `docs/pitch.md`.
