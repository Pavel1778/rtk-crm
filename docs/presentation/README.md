# Презентация RTK CRM (ЛЦТ 2026)

`RTK-CRM-LCT2026.pptx` — 11 слайдов, формат 16:9, шрифт Montserrat,
палитра шаблона ЛЦТ (`#FF0053`, `#520977`, `#310F53`).

Слайды собраны **строго на официальном шаблоне** `template-lct2026.pptx`
(файл организаторов). Блок презентации решения (позиции 1-6) оформлен на
макетах разделов, а обязательный блок организаторы требуют сохранять в
исходном дизайне — он занимает **позиции 7-11** и повторяет слайды 7-11
шаблона один в один: сетка, шрифты и цвета не менялись, заполнены только
плейсхолдеры. Позиции до 7-го слайда оформляются свободно.

Рабочий прототип: **https://crm-rtk.pixel-minds.ru** — этот адрес указан на
слайде с демонстрацией.

Разделы «Планы по развитию» и «Нагрузочный прогон» сведены в слайды 5 и 6,
контакты, QR и результаты — в слайд 6, чтобы уложиться в 11 слайдов без
потери обязательных блоков.

Слайд состава команды (позиция 9) рассчитан на 5 участников. Если команда
меньше, лишние карточки удаляются автоматически: `trim_team_slots()` убирает
неиспользуемые колонки, не трогая оставшиеся.

## Пересборка

Исходники генератора презентации в репозитории не хранятся: в сдачу идут
готовые артефакты `RTK-CRM-LCT2026.pptx` и `RTK-CRM-LCT2026.pdf`. Скриншоты
интерфейса лежат в `docs/images/`.

## Проверка вёрстки

```bash
python scripts/check_presentation_layout.py
```

Скрипт проверяет отрендеренную презентацию: текст за границей слайда,
наложения блоков, кегль не меньше 14pt на обязательных слайдах 7-11 и
совпадение сетки этих слайдов с исходным шаблоном. Если LibreOffice или
`pymupdf` недоступны, проверка рендера пропускается и скрипт не падает.

Просто конвертировать в PDF вручную:

```bash
soffice --headless --convert-to pdf --outdir /tmp/render \
  docs/presentation/RTK-CRM-LCT2026.pptx
```

Готовый PDF лежит рядом: `docs/presentation/RTK-CRM-LCT2026.pdf`.
Полная версия питча для речи — `docs/pitch.md`.
