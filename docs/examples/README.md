# Примеры отчётов

Файлы в этом каталоге — результат работы генератора отчётов на
демонстрационных данных. Персональных данных реальных лиц в них нет:
фикстуры для импорта собираются в памяти тестами
(`tests/test_excel_import.py`, `tests/test_import_report.py`) и используют
вымышленные значения.

## Почему нет файлов от кейсодержателя

Исходные выгрузки («Загрузка пользователей.xlsx», «Вендоры.xlsx»,
«Данные оплат.json») содержат персональные данные: СНИЛС, серию и номер
паспорта, адреса регистрации, телефоны и адреса электронной почты. Такие
файлы в репозиторий не попадают и перечислены в `.gitignore`.

API LMS и CMS кейсодержателем не предоставлен, поэтому интеграция работает
на заглушках (`INTEGRATION_MODE=mock`), а демонстрационные наборы
генерируются системой. Формат выгрузок повторяет согласованный маппинг
полей, поэтому переход на реальный API не требует изменения бизнес-логики.
