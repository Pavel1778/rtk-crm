## Слайд 1 — RTK CRM

- CRM для взаимодействия ИТ Школы Ростелекома с вузами
- Кейс №6, ЛЦТ 2026
- От первого контакта до контроля результата
- Команда: [указать состав]

**Речь:** Мы превращаем разрозненные коммуникации с вузами в единый управляемый
процесс с прозрачными этапами и ответственными.

## Слайд 2 — Проблема

- Данные распределены по таблицам и чатам
- Статус взаимодействия зависит от ручных обновлений
- Руководителю сложно видеть узкие места
- Отчёты собираются долго
- Риск потери истории и контрольных сроков

**Речь:** Проблема не в отсутствии данных, а в отсутствии единого рабочего
контекста и понятного следующего действия.

## Слайд 3 — Решение

- Kanban по 14 этапам workflow
- Карточка взаимодействия: вуз + продукт + договор
- Задачи, комментарии, файлы и история
- Отчёты и экспорт XLSX/XLS/PDF
- RBAC для КАМ, руководителей и администраторов

**Речь:** Пользователь видит состояние портфеля на одном экране и может сразу
обновить этап или зафиксировать результат коммуникации.

## Слайд 4 — Демонстрация

- Вход и дашборд с KPI
- Перемещение карточки между этапами
- Добавление задачи и комментария
- Настройка этапа администратором
- Графики и скачивание отчёта

**Речь:** Демо следует реальному сценарию КАМ: открыл портфель, обработал
контакт, зафиксировал действие, получил отчёт.

## Слайд 5 — Архитектура

- React + Vite + Ant Design на frontend
- FastAPI + SQLAlchemy Async на backend
- PostgreSQL в Supabase
- JWT, RBAC и audit middleware
- Render + Vercel; Yandex Cloud подготовлен как target

**Речь:** Текущий production-контур не ломается, а контейнерная упаковка
оставляет понятный путь к российскому облачному контуру.

## Слайд 6 — Технологии

- React 18, TypeScript, Recharts, dnd-kit
- Python 3.11, FastAPI, Pydantic v2
- PostgreSQL, asyncpg, SQLAlchemy 2
- Docker Compose и Nginx для миграции
- Locust для проверки нагрузки

**Речь:** Выбраны зрелые компоненты с низким порогом сопровождения и понятным
контрактом между UI, API и базой данных.

## Слайд 7 — 152-ФЗ и безопасность

- HTTPS и credentialed CORS
- JWT и ролевой контроль доступа
- Audit log для изменяющих операций
- Cookie consent и privacy policy
- Секреты только через окружение
- Подготовлена миграция БД в Yandex Cloud

**Речь:** Система не маскирует compliance декларациями: контролы отражены в
коде, документации и инфраструктурном плане.

## Слайд 8 — Нагрузка

- Сценарий Locust: login + 5 API-операций
- Цель: 50 пользователей, 60 секунд
- Целевой p95: менее 1000 мс
- Целевая ошибка: 0% или близко к 0%
- Локальный прогон: 1460 запросов, 0% ошибок

**Речь:** На локальном прогоне API отвечает устойчиво, но login поднял общий
p95 до 1600 мс. Это честно показывает следующую точку оптимизации.
