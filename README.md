# 🎓 Система контроля и обработки статистических данных по обучению студентов ВУЗов и школ по ИТ направлениям

> Решение для кейса №6 «ИТ Школа Ростелекома»  
> Международный хакатон «Лидеры цифровой трансформации 2026»

## 📋 О проекте
CRM-система для автоматизации 14-этапного процесса взаимодействия ИТ Школы Ростелекома с вузами. Система визуализирует workflow, контролирует жизненный цикл взаимодействий и сокращает трудозатраты сотрудников за счет автоматизации.

### Ключевые возможности (строго по ТЗ)
- 🗂 **Kanban-доска:** Визуализация 14 этапов workflow с drag-and-drop, комментированием и прикреплением файлов (10 форматов).
- 📊 **Отчетность:** Генерация отчетов в форматах **XLS, XLSX, PDF, JSON** с фильтрацией и выбором колонок.
- 🔗 **Интеграции:** Забор данных по API из LMS и веб-сайта на CMS Laravel (JSON).
- 🔐 **Безопасность:** Соответствие 152-ФЗ и Приказу ФСТЭК № 117 (Keycloak, RBAC, шифрование ПДн, логирование).
- ⚡ **Производительность:** Время отклика < 1 сек, SPA без перезагрузок, кэширование действий пользователя (Redis).
- 📱 **Адаптивность:** Полная поддержка десктопной и мобильной версий.
- 📖 **Документация:** Руководства пользователя и администратора со скриншотами, **встроенные непосредственно в платформу**.

## 🚀 Быстрый старт (Локальная разработка)

### Предварительные требования
- Docker Engine 24+ и Docker Compose v2+
- Git

### Запуск
```bash
# 1. Клонируйте репозиторий
git clone https://github.com/<ТВОЙ_НИК>/rtk-crm.git
cd rtk-crm

# 2. Создайте файл переменных окружения
cp .env.example .env

# 3. Поднимите все сервисы
docker-compose up -d --build

# 4. Откройте в браузере:
# Frontend: http://localhost:3000
# Backend (Swagger): http://localhost:8000/docs
# Keycloak Admin: http://localhost:8080
```

## 🔐 Безопасность и соответствие ТЗ
- ✅ Серверы размещены в РФ (Yandex Cloud) → 152-ФЗ.
- ✅ Чувствительные данные (ФИО) шифруются на уровне БД (Fernet).
- ✅ Все действия пользователей логируются для аудита (ФСТЭК № 117).
- ✅ Строгая ролевая модель (RBAC) через Keycloak.
