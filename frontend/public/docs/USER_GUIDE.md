# Руководство пользователя RTK CRM

## Обзор системы

RTK CRM — это система управления взаимодействиями с вузами-партнёрами для сопровождения внедрения ИТ-продуктов.

## Вход в систему

1. Откройте страницу входа
2. Введите email и пароль
3. Нажмите кнопку "Войти"

**Демо-доступ:**
- Администратор: admin@rtk.ru / admin123
- Менеджер: manager@rtk.ru / manager123
- КАМ: user@rtk.ru / user123

## Доска взаимодействий

### Просмотр карточек

- Каждая карточка отображает вуз, продукт, этап и ответственного
- Карточки можно перетаскивать между этапами
- Клик по карточке открывает детальную информацию

### Фильтрация

- **Поиск по вузу** — введите название вуза для фильтрации
- **Фильтр по продукту** — выберите ИТ-продукт из списка
- **Мобильный фильтр** — на телефоне выберите этап для отображения

### Создание взаимодействия

1. Нажмите кнопку "Создать взаимодействие"
2. Выберите вуз из списка
3. Выберите продукт (опционально)
4. Нажмите "Создать"

## Справочники

### Вузы

- Просмотр списка вузов
- Добавление нового вуза (для администраторов и менеджеров)
- Редактирование контактной информации
- Удаление вуза

### Продукты

- Просмотр списка ИТ-продуктов
- Добавление нового продукта
- Привязка к направлению

### Направления

- Просмотр списка ИТ-направлений
- Добавление нового направления

## Отчёты

### Просмотр показателей

- Всего вузов
- Активных взаимодействий
- Взаимодействий с договором
- Открытых задач
- Выполненных задач

### Экспорт данных

- **XLSX** — экспорт в формат Excel (современный)
- **XLS** — экспорт в формат Excel (совместимый со старыми версиями)
- **PDF** — экспорт в PDF для печати

## Настройки (только для администраторов)

### Управление пользователями

- Создание новых пользователей
- Назначение ролей (user, manager, admin)
- Редактирование пользователей
- Удаление пользователей

### Этапы воркфлоу

- Настройка 14 этапов взаимодействия
- Изменение порядка этапов
- Настройка цветов колонок
- Активация/деактивация этапов

## Файлы

### Загрузка файлов

1. Откройте карточку взаимодействия
2. Перейдите на вкладку "Файлы"
3. Перетащите файлы в область загрузки
4. Файлы загружаются автоматически

### Скачивание файлов

- Нажмите на иконку скачивания рядом с файлом
- Файл будет сохранён на ваше устройство

### Удаление файлов

- Нажмите на иконку удаления рядом с файлом
- Подтвердите удаление

## Выход из системы

Нажмите на иконку выхода в правом верхнем углу интерфейса.
