# Руководство администратора RTK CRM

## Роли пользователей

### User (КАМ)
- Просмотр взаимодействий
- Создание и редактирование назначенных взаимодействий
- Добавление файлов
- Просмотр отчётов

### Manager (Менеджер)
- Все права User
- Управление справочниками (вузы, продукты, направления)
- Создание взаимодействий
- Редактирование этапов взаимодействия

### Admin (Администратор)
- Все права Manager
- Управление пользователями
- Полный контроль над этапами воркфлоу
- Настройка системы

## Управление пользователями

### Создание пользователя

1. Перейдите в раздел "Пользователи"
2. Нажмите кнопку "Добавить пользователя"
3. Заполните поля:
   - Email (уникальный)
   - Полное имя
   - Пароль (минимум 6 символов)
   - Роль (user/manager/admin)
   - Статус активности
4. Нажмите "Создать"

### Редактирование пользователя

1. Нажмите кнопку редактирования рядом с пользователем
2. Измените необходимые поля
3. Нажмите "Сохранить"

### Удаление пользователя

1. Нажмите кнопку удаления рядом с пользователем
2. Подтвердите удаление
3. Нельзя удалить собственную учётную запись

## Этапы воркфлоу

### Настройка этапов

1. Перейдите в раздел "Пользователи"
2. Прокрутите до блока "Этапы воркфлоу"
3. Нажмите "Добавить этап"
4. Заполните поля:
   - Код (например, contact_search)
   - Название этапа
   - Порядок (1-14)
   - Цвет колонки
5. Нажмите "Добавить"

### Редактирование этапа

- Нажмите на название этапа для редактирования
- Введите новое название
- Нажмите Enter или кнопку "ОК"

### Изменение порядка

- Измените поле "Порядок" в таблице этапов
- Этапы автоматически сортируются по порядку

### Удаление этапа

- Нажмите кнопку "Удалить" рядом с этапом
- Этап можно удалить только если на нём нет взаимодействий
- При удалении взаимодействия переносятся на другой этап

## Безопасность

### Рекомендации по паролям

- Минимум 8 символов
- Используйте комбинацию букв, цифр и спецсимволов
- Не используйте легко угадываемые пароли

### Регулярное обновление

- Рекомендуется менять пароли каждые 90 дней
- Деактивируйте учётные записи уволенных сотрудников

## Аудит действий

Все действия пользователей записываются в журнал аудита в соответствии с 152-ФЗ.

## Интеграции

### LMS интеграция

- Синхронизация данных с системой управления обучением
- Импорт студентов и курсов
- Экспорт прогресса обучения

### Laravel интеграция

- Синхронизация с основным сайтом
- Импорт данных о вузах
- Экспорт отчётов

## Резервное копирование

Регулярные бэкапы базы данных выполняются автоматически.
