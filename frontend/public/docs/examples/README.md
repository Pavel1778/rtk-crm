# Примеры данных от кейсодержателя

Данные переданы кейсодержателем ЛЦТ 2026 как образцы форматов для проверки
функций импорта CRM. Рабочий прототип: https://crm-rtk.pixel-minds.ru

## ВАЖНО: данные обезличены

Файл `users_b2c.xlsx` **специально обезличен**: поля персональных данных
(СНИЛС, серия и номер паспорта, кем и когда выдан, код подразделения, адрес
регистрации, индекс) заменены на сгенерированные заглушки. Это сделано в
соответствии с требованиями 152-ФЗ «О персональных данных» — в публичном
репозитории и демо-контуре не должны храниться реальные ПДн.

Пересборка обезличенной копии из оригинала:
`python scripts/anonymize_case_data.py <путь к «Загрузка пользователей.xlsx»>`.
Оригинал хранится вне репозитория.

## Файлы

| Файл | Назначение | Статус ПДн |
| --- | --- | --- |
| `vendors.xlsx` | Каталог ИТ-продуктов и вендоров | Контакты — тестовые |
| `payments_b2c.json` | Заявки B2C (физлица на курсы) | ФИО/телефон — тестовые |
| `users_b2c.xlsx` | Анкета физлица | **ПДн обезличены** |

## Как использовать

1. **Импорт XLSX** — `vendors.xlsx` через UI → Справочники → Импорт.
2. **Импорт JSON** — `payments_b2c.json` через раздел Интеграция (mock LMS/CMS).
3. **Импорт анкеты** — `users_b2c.xlsx` через UI → Справочники.

Соответствует ТЗ раздел 4.1 (каталоги и импорт) и вопросам жюри
(диалоговый маппинг, поддержка XLS/XLSX/JSON) — см. `docs/qa-jury.md`.

## API от кейсодержателя

API LMS/CMS официально **не предоставлен** (уведомление организаторов ЛЦТ
2026). В проекте реализован адаптерный слой с mock-адаптерами. Замена на
real-адаптеры — одна строка в конфиге (`INTEGRATION_MODE=real`).
