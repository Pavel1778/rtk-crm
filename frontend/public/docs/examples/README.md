# Примеры данных от кейсодержателя

Данные переданы кейсодержателем ЛЦТ 2026 как образцы форматов для проверки
функций импорта CRM. Рабочий прототип: https://crm-rtk.pixel-minds.ru

## ВАЖНО: данные обезличены

Файл `users_b2c.xlsx` **специально обезличен**: поля персональных данных
(СНИЛС, серия и номер паспорта, кем и когда выдан, код подразделения, адрес
регистрации, индекс) заменены на сгенерированные заглушки. Это сделано в
соответствии с требованиями 152-ФЗ «О персональных данных» — в публичном
репозитории и демо-контуре не должны храниться реальные ПДн.

Пересборка обезличенной копии из оригинала:
`python scripts/anonymize_case_data.py <путь к «Загрузка пользователей.xlsx»>`.
Оригинал хранится вне репозитория.

## Файлы

| Файл | Назначение | Статус ПДн |
| --- | --- | --- |
| `vendors.xlsx` | Каталог ИТ-продуктов и вендоров | Контакты — тестовые |
| `payments_b2c.json` | Заявки B2C: курсы для каталога продуктов | ФИО/телефон — тестовые |
| `users_b2c.xlsx` | Анкета физлица (учётные записи) | **ПДн обезличены** |

## Как использовать

Все три файла проходят через разделы «Справочники» и «Интеграция»:

1. **Каталог вендоров** — `vendors.xlsx` через UI → Справочники → Импорт,
   тип каталога «Продукты» (endpoint `POST /api/catalogs/import/preview`).
   Колонка «Продукт» распознаётся как название ИТ-продукта.
2. **Каталог курсов** — `payments_b2c.json` через UI → Справочники →
   Импорт JSON, тип каталога «Продукты» (endpoint
   `POST /api/catalogs/import/json/preview`). Колонка «Курс» также
   описывает ИТ-продукт (ТЗ 4.1), поэтому заявки B2C наполняют каталог
   курсов. Файл начинается с `null` — служебная строка пропускается.
3. **Учётные записи** — `users_b2c.xlsx` через UI → Справочники → Импорт,
   тип каталога «Пользователи». Обязательна колонка `Email`; колонки ПДн
   игнорируются.

> **Важно:** раздел «Интеграция» (mock LMS/CMS) принимает другой контракт —
> обязательные поля `external_id` и `university` (см. `GET /api/integration/schema`).
> Выгрузка B2C-заявок этому контракту не соответствует и через «Интеграцию»
> не загружается — используйте пункт 2 выше.

Соответствует ТЗ раздел 4.1 (каталоги и импорт) и вопросам жюри
(диалоговый маппинг, поддержка XLS/XLSX/JSON) — см. `docs/qa-jury.md`.

Проверка на реальных файлах: `tests/test_examples_import.py` открывает
образцы из этой папки и прогоняет их через те же парсеры, что и UI.

## API от кейсодержателя

API LMS/CMS официально **не предоставлен** (уведомление организаторов ЛЦТ
2026). В проекте реализован адаптерный слой с mock-адаптерами. Замена на
real-адаптеры — одна строка в конфиге (`INTEGRATION_MODE=real`).

Скриншоты интерфейса лежат в `docs/images/`, полные руководства —
в `docs/USER_GUIDE.md` и `docs/ADMIN_GUIDE.md`.
